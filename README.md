# TSG 小游戏宇宙

纯静态、离线可运行的 TSG 主题小游戏合集，共 12 个游戏。

## 在线游玩

GitHub Pages：`https://gcctkh5sky-ui.github.io/TSG/`

## 游戏列表

- 合成tsg
- TSG 2048
- TSG 打地鼠
- TSG 打砖块
- TSG 记忆翻牌
- TSG 扫雷
- TSG 贪吃蛇
- TSG 俄罗斯方块
- TSG 五子棋
- TSG 消消乐
- TSG 颜色大挑战
- TSG 一跳

## 项目结构

- `index.html`：游戏大厅
- `assets/`：公共样式、脚本、卡片封面与 TSG 图片
- `games/`：12 个游戏

本项目为纯 HTML/CSS/JavaScript 静态站点，可直接部署到 GitHub Pages。
